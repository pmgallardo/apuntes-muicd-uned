## GAINE.EX.2024SO.8

### Enunciado GAINE.EX.2024SO.8

Tenemos una base de datos de Neo4j que se ha configurado mediante el siguiente bloque de comandos en Cypher:

```cypher
CREATE (p1:Persona {nombre: "Carlos", edad: 28, ciudad: "Madrid"})
CREATE (p2:Persona {nombre: "Elena", edad: 34, ciudad: "Barcelona"})
CREATE (p3:Persona {nombre: "David", edad: 22, ciudad: "Sevilla"})
MATCH (x:Persona {nombre: "Carlos"}), (y:Persona {nombre: "Elena"})
CREATE (x)-[:CONOCE]->(y)
MATCH (y:Persona {nombre: "Elena"}), (z:Persona {nombre: "David"})
CREATE (y)-[:CONOCE]->(z)
```

Si queremos actualizar el nodo correspondiente a Carlos para modificar el valor de su propiedad edad a 29 años, ¿cuál es la sintaxis correcta?

a. SET p1.edad = 29  
b. MATCH (p:Persona {nombre: "Carlos"}) SET p.edad = 29  
c. UPDATE (p:Persona {nombre: "Carlos"}) SET p.edad = 29  
d. Ninguna de las restantes.  

### Solución GAINE.EX.2024SO.8

B
