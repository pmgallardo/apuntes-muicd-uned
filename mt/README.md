# Minería de textos

En esta carpeta se incluyen recursos de apoyo educativo para la asignatura de Minería de textos del Máster Universitario de Ingeniería y Ciencia de Datos (MUICD) de la UNED.

Puedes consultar también la [ficha oficial](https://www.uned.es/universidad/inicio/estudios/masteres/master-universitario-en-ingenieria-y-ciencia-de-datos.html).

## Evaluación

| Tarea | % nota final |
| - | - |
| PECs | 40 |
| Exámen | 60 |

## Exámen

Número de preguntas: 6.
Tiempo: 120 minutos.
Material permitido: calculadora.

## Bibliografía

- Básica
  - Presentaciones propias de la asignatura.
  - Steven Bird, Ewan Klein, Edward Loper. [Natural Language Processing with Python](https://www.oreilly.com/library/view/natural-language-processing/9780596803346/). O'Reilly, 2009.
  - Steven Bird, Ewan Klein, Edward Loper. [Natural Language Processing with Python](https://www.nltk.org/book/).
  - JURAFSKY, Dan, MARTIN, James H. [Speech and Language Processing. An Introduction to Natural Language Processing, Computational Linguistics, and Speech Recognition with Language Models](https://web.stanford.edu/~jurafsky/slp3/). Borrador 3.ª ed. Enero 2026.
- Complementaria
  - LIU, Yang, DENG, Li. Deep Learning in Natural Language Processing. Springer, 2018.
