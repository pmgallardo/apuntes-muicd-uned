## EX.2026F2.1

Tema: 2, "Extracción de la información", "Expresiones temporales".

### Enunciado EX.2026F2.1

¿Cuáles son las tres clases principales de expresiones temporales que se identifican en los textos? Enumérelas, defina cada una de ellas e ilustre con un ejemplo cada categoría.

### Solución EX.2026F2.1

Existen tres tipos principales de expresiones temporales:

1. **Absolutas:** Se corresponden con una fecha, hora o momento concreto y específico en el tiempo. Ejemplo: "24 de abril de 1916" o "10:15 AM".
2. **Relativas:** Hacen referencia a un momento en el tiempo en relación con otro punto, generalmente el momento de creación del texto o el contexto actual (ancla temporal). Ejemplo: "ayer", "el próximo semestre" o "hace dos semanas".
3. **Duraciones:** Indican un periodo, intervalo o longitud de tiempo de distinta granularidad. Ejemplo: "cuatro horas" o "tres semanas".

## EX.2026F2.2

Tema: 2, "Extracción de la información", "Reconocimiento de entidades".

### Enunciado EX.2026F2.2

A partir del siguiente etiquetado de entidades mediante anotación IOB, determine los valores de precisión, cobertura (recall) y medida-F obtenidos por el modelo bajo evaluación (última columna) en contraste con el estándar de referencia (gold standard, segunda columna).

| Palabra | Referencia | Modelo evaluado |
|---|---|---|
| La | O | O |
| presidenta | O | B |
| María | B | I |
| Fontaneda | I | |
| visitó | O | |
| Madrid | B | |
| para | O | OOB000 |
| reunirse | O | |
| con | O | |
| el | O | O |
| rector | | B |
| de | O | O |
| la | O | O |
| Universidad | B | B |
| Complutense | I | B |
| y | O | O |
| anunciar | O | O |
| nuevos | O | O |
| programas | | |
| culturales | O | O |

### Solución EX.2026F2.2

En la evaluación del reconocimiento de entidades, se contabiliza como acierto únicamente cuando los límites y la clasificación de la entidad coinciden exactamente con la referencia.

1. **Entidades en la Referencia (Gold Standard) [N]:** 3 entidades

   * "María Fontaneda" (B, I)
   * "Madrid" (B)
   * "Universidad Complutense" (B, I)

2. **Entidades extraídas por el Modelo [E]:** 5 entidades

   * "presidenta María" (B, I) -> Incorrecta (límites erróneos)
   * "Madrid" (B) -> Correcta
   * "rector" (B) -> Incorrecta (falso positivo)
   * "Universidad" (B) -> Incorrecta (fragmentada)
   * "Complutense" (B) -> Incorrecta (fragmentada)

3. **Entidades correctas [C]:** 1 entidad ("Madrid")

**Cálculo de métricas:**

* **Precisión:** C / E = 1 / 5 = 0.20 (20%)
* **Cobertura (Recall):** C / N = 1 / 3 = 0.3333 (33,33%)
* **Medida-F:** (2 * Precisión * Cobertura) / (Precisión + Cobertura) = (2 * 0.20 * 0.3333) / (0.20 + 0.3333) = 0.1333 / 0.5333 = 0.25 (25%)

## EX.2026F2.3

Tema: 2, "Extracción de la información", "Extracción de relaciones".

### Enunciado EX.2026F2.3

Explique en qué consiste el procedimiento de extracción de relaciones basado en supervisión distante.

### Solución EX.2026F2.3

La supervisión distante es un enfoque semisupervisado que permite entrenar extractores de relaciones sin necesidad de etiquetar un corpus manualmente. 

El método consiste en utilizar una gran base de datos existente (o base de conocimiento) para obtener automáticamente un enorme conjunto de tuplas de entidades que se sabe que están relacionadas (semillas). A continuación, se buscan estas tuplas en una gran colección de textos sin anotar (como Wikipedia) y se extraen todas las oraciones donde ambas entidades coaparecen. El sistema asume, aunque introduzca cierto ruido, que esas oraciones expresan la relación objetivo. A partir de ellas, se extraen numerosos rasgos léxicos y sintácticos, conformando vectores de características con los que finalmente se entrena un clasificador supervisado convencional capaz de predecir dicha relación en textos nuevos.

## EX.2026F2.4

Tema: 3, "Representación de documentos", "Modelos de representación".

### Enunciado EX.2026F2.4

En el marco de los modelos semánticos de representación vectorial (Vector Semantic Model), precise qué diferencia fundamental separa a los modelos contextualizados de aquellos independientes de contexto. Proporcione asimismo un ejemplo de modelo contextualizado y describa brevemente su operativa.

### Solución EX.2026F2.4

Los **modelos independientes del contexto** (como Word2Vec o GloVe) generan una única representación vectorial estática para cada palabra del vocabulario, independientemente de la oración en la que aparezca. Esto provoca que palabras polisémicas (como "banco" para sentarse o "banco" de dinero) reciban siempre el mismo vector. Por el contrario, los **modelos contextualizados** generan una representación dinámica para cada palabra basándose en el resto de las palabras que la rodean en esa oración específica, resolviendo el problema de la polisemia.

Un ejemplo de modelo contextualizado es **BERT**. Funciona empleando una arquitectura de red profunda tipo *Transformer* bidireccional basada en mecanismos de auto-atención. En lugar de procesar la oración secuencialmente, captura la información de todas las palabras al mismo tiempo. Se preentrena enmascarando un porcentaje de las palabras de entrada e intentando predecirlas utilizando simultáneamente todo el contexto previo y posterior de la secuencia.

## EX.2026F2.5

Tema: 4, "Clustering y clasificación", "Clasificación".

### Enunciado EX.2026F2.5

Los sistemas de clasificación se dividen habitualmente en monoetiqueta (single-label) y multietiqueta (multi-label). A este respecto:

1. Detalle en qué consiste la diferencia entre ambos enfoques de clasificación.
2. Plantee un caso práctico que se adapte a la clasificación monoetiqueta y otro que encaje en la clasificación multietiqueta.
3. ¿Resulta viable abordar una tarea de clasificación multietiqueta empleando metodologías de clasificación monoetiqueta? Justifique debidamente su respuesta.

### Solución EX.2026F2.5

(i) La **clasificación mono-etiqueta (single-label)** restringe el sistema a asignar a cada documento una y sólo una categoría del conjunto de clases disponibles. La **clasificación multi-etiqueta (multi-label)** permite que el modelo asigne a un mismo documento un número variable de categorías simultáneamente, pudiendo ir desde ninguna hasta todas las posibles.

(ii) **Ejemplo mono-etiqueta:** Un sistema de análisis de polaridad (sentimiento) que debe determinar si una reseña es estrictamente "Positiva", "Negativa" o "Neutra". **Ejemplo multi-etiqueta:** Un clasificador automático de noticias donde un solo artículo sobre normativas de exportación puede ser etiquetado al mismo tiempo como "Política", "Economía" y "Comercio Internacional".

(iii) Sí, es posible abordar la clasificación multi-etiqueta mediante métodos mono-etiqueta transformando el problema general en múltiples tareas de clasificación binaria (que es un caso particular de mono-etiqueta). Para ello, se entrena un clasificador individual para cada categoría existente que determine con un "Verdadero" o "Falso" si esa clase concreta aplica al documento, evaluando todos los pares documento-categoría de forma independiente.

## EX.2026F2.6

Tema: 4, "Clustering y clasificación", "Clustering".

### Enunciado EX.2026F2.6

Imagine que una organización desea implementar, partiendo de cero y careciendo de registros etiquetados, un sistema capaz de clasificar por temáticas los comentarios de sus usuarios, considerando que un mensaje puede abordar diversas cuestiones (por ejemplo, incidencias con envíos, peticiones de nuevos productos o servicios, etc.). ¿Cómo plantearía la resolución de este reto: mediante técnicas de clasificación (especificando subtipo) o mediante clustering (especificando subtipo)? Fundamente su respuesta y proponga una solución detallada.

### Solución EX.2026F2.6

El problema debe abordarse mediante técnicas de **Clustering** (agrupamiento), ya que se enmarca dentro del aprendizaje no supervisado.

**Justificación:**  
Al querer desarrollar el sistema desde cero y sin disponer de un corpus previo de datos etiquetados con categorías temáticas, es imposible entrenar un modelo de clasificación automática. El clustering permite organizar lógicamente la colección de comentarios descubriendo patrones, temáticas latentes y agrupando los textos más similares entre sí sin conocer las categorías de antemano.

**Posible solución:**

1. **Preprocesamiento y Representación:** Se normalizarían los textos de los usuarios, eliminando palabras vacías y aplicando un proceso de *stemming* o lematización. Luego, se convertirían en vectores utilizando una matriz término-documento ponderada con TF-IDF o representaciones semánticas distribuidas (*embeddings* densos).
2. **Algoritmo de Clustering:** Se aplicaría un **Topic Model** estadístico (como *Latent Dirichlet Allocation - LDA*), el cual asume que los comentarios son una mezcla de temas y extrae probabilísticamente los conceptos latentes de las quejas o peticiones. Alternativamente, se podría usar un algoritmo de partición basado en centroides como **K-means**, fijando un número exploratorio de clústeres (*k*) para segmentar automáticamente los comentarios en grupos temáticos bien diferenciados.
